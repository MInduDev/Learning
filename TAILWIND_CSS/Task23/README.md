# Task 23 - Greenwood Public Library Website

## About Project

This project is a responsive **Greenwood Public Library website** built using **HTML5 and Tailwind CSS**. The main goal of this task was to practice creating a modern, responsive multi-section website using Tailwind CSS utility classes without writing custom CSS.

The website presents a complete library landing page with sections for the library introduction, available sections, spaces, membership plans, testimonial, contact information, upcoming events, and footer navigation.

## Features

- Sticky navigation bar
- Responsive navigation links
- Library status badge
- Hero section with call-to-action buttons
- Responsive hero image
- Library statistics section
- "Our Sections" grid with hover effects
- "Inside The Library" gallery section
- Responsive image gallery
- "Why Greenwood" feature cards
- About/introductory content section
- Library membership plans
- Popular membership plan badge
- Membership cards with hover effects
- Customer testimonial section
- Contact and opening-hours section
- Get Directions button
- Email contact link
- Upcoming events section
- Responsive footer
- Footer navigation links
- Social media placeholders
- Image hover and scale effects
- Responsive layouts for mobile, tablet, and desktop screens

## Technologies Used

- HTML5
- Tailwind CSS (CDN)
- Font Awesome
- Responsive Design
- Flexbox
- CSS Grid

## Responsive Design Concepts Used

- Mobile-first responsive design
- Flexbox layouts
- CSS Grid layouts
- Tailwind responsive breakpoints such as `sm`, `md`, and `lg`
- Responsive typography
- Responsive spacing
- Responsive images
- Sticky positioning
- Hover and transition effects
- Responsive multi-column layouts


## How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Make sure you have an active internet connection because Tailwind CSS and Font Awesome are loaded through CDN.
5. Resize the browser window to test the responsive design on different screen sizes.
