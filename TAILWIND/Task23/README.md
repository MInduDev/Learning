# Task 22 - Project Workspace Landing Page

## About Project

This project is a modern Project Workspace landing page made using HTML, Tailwind CSS, and JavaScript. It helps introduce a digital workspace platform where teams can write, plan, share, and collaborate with AI tools.

## Features

- Sticky Navbar
- Responsive Hero Section
- Mobile Hamburger Menu
- Gradient Background
- Call-To-Action Buttons
- Dashboard Preview Section
- Floating Tasks Card
- Project Status Card
- Team Activity Card
- Fixed Chat Widget
- Responsive Layout

## Technologies Used

- HTML
- Tailwind CSS CDN
- JavaScript
- CSS

## How to Run

1. Download the project folder.
2. Open it in VS Code.
3. Make sure `index.html`, `style.css`, and `script.js` files are in the same folder.
4. Open `index.html` in a browser.
5. Explore the landing page and click the menu or chat button.

## What I Learned

- How to create a landing page using Tailwind CSS.
- How to use sticky, relative, absolute, and fixed positioning.
- How to create a responsive mobile menu with JavaScript.
- How to add simple interactive features like a chat button.
