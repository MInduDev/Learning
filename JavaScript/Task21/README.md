# Task - OmniFood - Responsive Food Delivery Landing Page

## Project Overview

OmniFood is a responsive single-page food delivery landing page developed as a front-end practice project.

The main purpose of this project is to practice the basics of HTML5 and CSS3 by creating a complete landing page based on the provided OmniFood reference screenshots.

The website represents a healthy food delivery service where users can learn about the service, understand how it works, explore the cities where the service is available, read customer testimonials, and view different pricing plans.

The project mainly focuses on:

- Creating a proper HTML page structure
- Designing layouts using CSS
- Using Flexbox and CSS Grid
- Working with background images
- Adding dark overlays on images
- Creating buttons and cards
- Making images responsive
- Creating responsive layouts for desktop, tablet, and mobile
- Maintaining proper spacing and alignment
- Practicing clean and beginner-friendly CSS

---

## Project Objectives

The main objectives of this project are:

1. To understand how to structure a complete single-page website using HTML5.
2. To practice CSS styling and page layouts.
3. To understand how Flexbox can be used for navigation and alignment.
4. To understand how CSS Grid can be used for cards and multi-column layouts.
5. To practice responsive web design using CSS media queries.
6. To work with background images and image overlays.
7. To create reusable buttons and card styles.
8. To make the website usable on different screen sizes.
9. To reproduce the basic layout and visual style of the provided OmniFood screenshots.

# Website Sections

## 1. Header + Hero Section

The first section of the website is the Header and Hero section.

### It contains:

- OmniFood circular logo
- Navigation menu
- Food Delivery
- How It Works
- Our Cities
- Sign-Up
- Main heading
- "I'm Hungry" button
- "Show me more" button
- Background food image
- Dark overlay

### Hero Heading

The main heading used in the hero section is:

> GOODBYE JUNK FOOD  
> HELLO SUPER HEALTHY FOOD

### Navigation

The navigation menu contains:

- Food Delivery
- How It Works
- Our Cities
- Sign-Up

The navigation is displayed horizontally on larger screens.

On smaller screens, the navigation layout changes to make it easier to use on mobile devices.

#### Step 2
